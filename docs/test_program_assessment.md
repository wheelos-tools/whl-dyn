# 测试项合理性与业界实践评估

本文按 `whl-dyn` 的职责评估已有测试项，并记录改进建议。**建议不表示功能已经实现或车辆已经通过验收**；当前能力以[测试项清单](current_test_cases.md)、对应代码及测试为准。本文基于 2026 年 11 月的代码和公开标准范围；车速覆盖等实验结论仅适用于当时的实验数据。

## 结论与边界

工具的核心职责是**油门/制动标定**和**底盘动力学测量与辨识**。测试方向总体合理，但目前更适合研发和集成验证，不能直接认定为量产标定或标准化车辆验收方案。主要差距在工况覆盖、信号质量、辨识有效性、重复性和独立验证。

控制器闭环跟踪是可选的集成扩展，不是开环标定的前提。ESP/ESC 不属于本工具的必选测试项。闭环跟踪测量的是控制器、定位与车辆的联合表现，不代替底盘本体测试。

以下 ISO/SAE 标准仅用于比较公开的适用范围，不宣称本工具符合标准。适用车型、完整方法及合规要求应对照正式标准核查，不能仅按名称或测试动作判断。

## 逐项评估

| 测试项 | 评价 | 差距与建议 |
| --- | --- | --- |
| LON-CAL：油门/制动标定 | 核心且必要。不同指令下记录速度和净加速度，可建立纵向标定关系。制动从较高速度减速，可沿途覆盖较低速度。 | 此前仿真实验主要覆盖约 0–1.5 m/s，不能代表实际运行域。按目标车速、指令、载荷、坡度、动力系统状态及重复次数规划工况；统计每格样本数、有效覆盖和不确定度，并以独立试验验证。 |
| LON-CAL：滑行与响应阈值 | 滑行基线有助于区分道路阻力和执行器作用；相对滑行的响应阈值不等于执行器内部死区。 | 建立明确的滑行采集计划并记录档位、再生制动状态、坡度和环境。SAE J2263 的道路阻力滑行测试有特定条件和速度范围，当前低速 Drive 滑行不能直接称为符合该标准。 |
| LON-CAL：质量与导出 | 保留净加速度、未测区域不外推、控制文件不写非有限值的方向合理。 | 在现有导出基础上增加覆盖率、每格样本数、重复性和缺失范围；样本内拟合误差不是独立预测精度。消费者必须明确处理稀疏有效域。 |
| LON-DYN：纵向阶跃 | 可测油门/制动指令到车辆运动的复合响应。 | 加减速时车速在变化，输出不一定达到稳态或符合一阶模型。报告速度窗口、实际反馈、拟合误差和稳态有效性；不得将指令到加速度的延迟直接称为纯执行器延迟。 |
| LON-DYN：纵向频响 | 有辨识价值，但优先级低于基础标定和阶跃。 | 连续激励可能改变车速，线性时不变假设不一定成立。建议在受控速度窗口内采用小幅激励，分别辨识“指令→执行器反馈”和“反馈→加速度”，用重复试验或已知模型核验。 |
| LON-DYN：Ramp/Pulse/Triangle/Hysteresis | 保留原始激励与采集能力合理。 | 当前没有对应专用定量分析器。应分别定义响应阈值和斜率、短时响应、上升/下降路径与滞环面积等指标和有效性判据后，才能声称完成对应辨识。 |
| LAT-OL-STEP：转向阶跃 | 核心测试；与 ISO 7401 的横向瞬态开环测试范围方向一致。 | 扩展多速度、多幅值、左右、回正和重复工况；分别报告指令→实际转向反馈、实际转向→横摆/横向加速度，验证初始稳态、单位、符号及实际激励。 |
| LAT-OL-RAMP：转向慢 Ramp | 有助于观察低速渐变反馈。 | 已观察到的反馈变化率不是认证的执行器最大速率。建议补充基于噪声阈值的响应起点、正反向差异和回程滞环分析。 |
| LAT-OL-FRF：横向频响 | 合理，但频率覆盖和带宽结论必须经过质量检查。 | 默认频响估计分段最多 256 点，频率间隔在 50 Hz 时约 0.195 Hz、100 Hz 时约 0.391 Hz；计划中 0.05–0.5 Hz 的低频分辨率可能不足。应根据最低频率、时长和有效分段数设计估计，用定频驻留或已知模型交叉验证；高相干性本身不证明结果可靠。 |
| LAT-SS：固定转向稳态 | 合理；与 ISO 4138 的稳态圆周开环测试范围方向一致。 | 当前是固定转向、多速度，**不是固定半径**。欠转向梯度需要有效道路车轮角、轴距和实测曲率；`r/v` 曲率近似在侧偏较大时有限制。增加跨运行聚合、置信区间和左右差异分析。 |
| LAT-CL：闭环轨迹跟踪 | 适合作为控制器集成扩展。 | 需要运行中的控制器及有效调试数据；结果不能代替底盘本体辨识，也不应阻塞开环标定。 |

对应实现、分析输入和已知限制见[纵向工作流](vehicle_dynamics.md)、[横向能力评估](open_loop_lateral_identification_assessment.md)和[测试项清单](current_test_cases.md)。

## 改进优先级

### P0：先保证结果可用

1. 为每次试验记录车辆配置、负载、路面/坡度、天气、信号单位与坐标系、软件版本和仿真模型版本；记录时钟、信号时间差、丢帧和数据有效域。ISO 15037-1 强调试验条件对结果可比性的影响。
2. 区分**执行完成、数据有效、参数可辨识、满足车辆验收要求**。现有 Phase 1 `PASS` 表示执行及可观察响应检查通过，`vehicle_acceptance` 仍为 `NOT_EVALUATED`，不是车辆性能合格。
3. 报告标定覆盖率、每格样本数、缺失范围及重复性；预留独立运行的数据验证误差。不得把缺失区域的插值或样本内残差当成验收依据。
4. 在仿真端到端和真实车辆使用前验证紧急停止、反馈丢失、模式切换和超限后的完整行为。软件安全停车不能代替独立的车辆级安全机制。

### P1：提高辨识可信度

1. 优先完善纵向阶跃、转向阶跃和稳态转向：增加实际执行器反馈、稳态检测、左右与回正、重复试验及不确定度。
2. 按频率范围设计采样率、分段长度和试验时长；验证速度稳定性、激励幅值、频率覆盖与有效分段数。相位延迟不是纯通信或执行器延迟。
3. 完善滑行计划和制动预加速；是否需要更多制动起始速度，由有效数据覆盖和重复性决定，而不是由 case 数量决定。

### P2：按需求扩展

补齐脉冲/滞环等专用分析、跨工况报告及可选轮胎/侧偏信号。闭环跟踪验收按实际控制器集成需求开展；没有可靠信号时，轮胎利用率或车辆极限应明确标记不可用。

## 依据与范围

- [ISO 7401:2011：横向瞬态响应开环测试](https://www.iso.org/standard/54144.html)，适用于标准所列乘用车及轻型货车。
- [ISO 4138:2021：稳态圆周驾驶行为开环测试](https://www.iso.org/standard/81710.html)，适用于标准所列乘用车及轻型货车。
- [ISO 15037-1:2019：乘用车车辆动力学测试一般条件](https://www.iso.org/obp/ui/#!iso:std:70164:en)。
- [SAE J2263：道路阻力滑行测量](https://saemobilus.sae.org/standards/j2263_202005-road-load-measurement-using-onboard-anemometry-coastdown-techniques)，用于道路阻力测量，不等同于当前低速 Drive 滑行标定。
- [MathWorks：基于仿真的频率响应估计](https://www.mathworks.com/help/slcontrol/ug/frequency-response-estimation-using-simulation-based-techniques.html)，讨论扫频与定频激励的适用性。
